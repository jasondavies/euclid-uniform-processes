# Short remainder-only gcd certificates

Every pair a ≥ b has a remainder-only derivation of gcd(a, b) using
O(log a / log log a) remainder calls. Each call takes the remainder of two values
already available, starting from a and b; earlier values are kept and no numerical
constants are introduced. Euclid needs up to about 2 log₂ a calls.

As a consequence, the intrinsic calls(rem)-complexity of both coprimeness and gcd in
the Euclidean structure Nε = (N, rem, eq0, eq1) is o(log a), uniformly over the second
input. This refutes the uniform-process form of van den Dries and Moschovakis's
conjecture that the Euclidean algorithm is optimal among its peers:

- **Conjecture 3.4** of Moschovakis's 2012 notes, *Absolute lower bounds for uniform
  processes*: there is no r > 0 with calls(rem)(Nε, ⊥⊥, a, b) ≥ r log a for infinitely
  many a ≥ b ≥ 1. In Lean this is `ShortGCD.not_conjecture_3_4`.
- **The "precise version" (4F-5) of the Main Conjecture** in *Abstract Recursion and
  Intrinsic Complexity* (2019, p. 151): there is no K > 0 with
  2 log max(x, y) ≤ K · calls(rem)(gcd, x, y) on infinitely many pairs. In Lean this is
  `ShortGCD.not_main_conjecture_4F5`.
- **The possibility raised after Corollary 6C.7 (p. 188)**, that the Main Conjecture
  "holds for all uniform processes of Nε".

**The deterministic Main Conjecture remains open.** The construction does not give a
deterministic algorithm with this cost, because choosing which two stored residues to
combine is not charged. It does show that a proof of the Main Conjecture must use
determinism. A lower bound for intrinsic complexity, which is what the homomorphism
method proves, cannot exceed log a / log log a.

Read `paper/short-gcd-certificates.pdf`, built from `paper/short-gcd-certificates.tex`. Citations refer to
printed pages of Moschovakis, *Abstract Recursion and Intrinsic Complexity* (Cambridge
University Press / ASL, 2019).

**Status.** The whole argument is machine-checked in Lean, as listed below. A second,
independent Lean formalisation of the same argument was developed separately. The result
has not yet been reviewed by an expert in the area.

### Main results

The conjectures:

- `ShortGCD.not_conjecture_3_4` and `ShortGCD.not_main_conjecture_4F5` state the two
  refutations above. The intrinsic complexities `callsCoprimeness` and `callsGcd` are
  defined directly from certificates. A certificate is a finite partial substructure
  generated by the input, such that every map preserving its facts respects the relation
  or function.
- `ShortGCD.eventually_calls_le`: for every ε > 0, eventually in M, both intrinsic
  complexities are at most ε log₂ M on all pairs bounded by M.
- `ShortGCD.callsCoprimeness_eq_callsRem`: on coprime pairs, `callsCoprimeness` agrees
  with the `callsRem` of the existing reduction, which equals D(a, b).

Derivations and certificates:

- `ShortGCD.uniform_real_bound`: one real constant bounds G(a, b), for every a ≥ 4 and
  b ≤ a, by C · logb 2 a / logb 2 (logb 2 a).
- `ShortGCD.sizeCost_isBigO` and `ShortGCD.sizeCost_isLittleO_log`: worst-case Big-O and
  little-o statements, taking the maximum over all smaller inputs.
- `ShortGCD.uniform_gcd_certificates`: generated gcd certificates with at most the same
  bound plus two remainder facts, and no eq1 facts.
- `ShortGCD.coprime_certificate_bound` and `noncoprime_certificate_bound`: both truth
  values of coprimeness have certificates within the corresponding bound.
- `ShortGCD.G_eq_D`: agreement with the existing minimal derivation definition.
- `ShortGCD.gcd_certificate_lower`: every generated gcd certificate has at least G(a, b)
  remainder facts.

### Proof path

Derivation / Composition → Gap and Prefix → Contraction → Euclid → FiniteBound →
Arithmetic → UpperBound → Asymptotic → Certificates → Conjecture.

- **The finite recurrence.** The core is `sizeCost_step`. Its hypotheses concern
  natural-number size parameters, not an assumed complexity bound.
- **The bound.** Arithmetic discharges those hypotheses, and UpperBound proves the
  resulting bound by strong induction.
- **The logarithms.** Asymptotic compares integer logarithms with real logarithms.
- **The conjectures.** Conjecture turns the bounds into the two refutations.

### Soundness and scope

- **No added assumptions.** The development has no `sorry`/`admit` placeholders and adds
  no axioms. The recorded axiom audit (`validation/axioms.txt`) uses only `propext`,
  `Classical.choice` and `Quot.sound`.
- **What is cited, not formalised.** The book's general best-uniform-process theorem
  (4F.1) is cited in the manuscript; the abstract theory of uniform processes is not
  re-formalised here. The refutations need no such theory, because they are stated
  about intrinsic complexities defined directly from certificates.
- **Conventions.** The certificate semantics use the total relation `Nat.Coprime` on
  natural numbers. A convention requiring positive inputs can add eq0 facts without
  adding remainder calls.

## Reproducing finite checks

```
python3 scripts/check_certificates.py
python3 remainder_only_certificate.py
python3 scripts/check_prefix_lemma.py
```

- **`scripts/check_certificates.py`** runs a 310-case suite. It covers zero inputs, equal
  inputs, scaled non-coprime inputs, random large inputs and Fibonacci pairs. It also
  checks that four invalid traces are rejected.
- **`remainder_only_certificate.py`** reproduces the three numerical examples in the
  manuscript.
- **`scripts/check_prefix_lemma.py`** checks the Euclidean-prefix lemma exhaustively for
  every coprime a < 1500, every prefix length, and 60 moduli above the threshold
  2a/r_h, which is 254,722,179 instances. As a control it counts collisions when the
  threshold is dropped, which shows the test can fail.

Results are in `validation/`. The planner uses unrestricted arithmetic; only the
remainder facts it returns are counted as instructions. These finite checks supplement
the Lean proof.
